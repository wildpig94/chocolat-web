# 🎂 Pastelería Chocolat — Sitio web

Sitio de **Pastelería Chocolat**, repostería fina en Apatzingán, Michoacán.

**"Repostería fina que endulza tus celebraciones."**

## 🌐 En línea
**https://wildpig94.github.io/chocolat-web/**

## 📁 Estructura
```
chocolat-web/
├── index.html        → Página principal
├── css/estilos.css   → Diseño (amarillo + café, tonos de la fachada)
├── js/galeria.js     → Galería estructurada por categorías
├── js/principal.js   → Menús desplegables, lightbox, pedido→WhatsApp
└── imagenes/         → Fotos de repostería + logo de cerezas
```

## ✏️ Cómo actualizar
| Qué | Dónde |
|---|---|
| Precios / productos | Sección `especialidades` y `eventos` en `index.html` |
| Datos de sucursales | Sección `ubicacion` + `js/principal.js` (WHATSAPP) |
| Fotos | Reemplaza archivos en `imagenes/` |
| Galería | `js/galeria.js` → array `GRUPOS` |

## 🌍 Publicación
El sitio se sirve desde la rama `main` (GitHub Pages).
